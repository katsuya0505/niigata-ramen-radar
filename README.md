# 新潟ラーメンレーダー v0.6

## 今回の修正
v0.5で残った過去の誤検知を完全に切り離しました。

v0.6は **current-scan-only** です。
つまり、以前の `2026年上半期版`、`年に一度のお祭りが今年も`、
`今しか食べられない`、`イオン新潟青山店` のような古い誤検知を
履歴から復活させません。

### 掲載条件をさらに厳格化
- 5選 / 6杯 / まとめ / 特集 / スタンプラリーは除外
- 店名として不自然な見出し語を除外
- 「店舗名らしい固有名詞」を取れない記事は除外
- 現在のスキャンで通った情報だけを掲載

### 写真
- 記事内画像を調べ、ラーメン・料理・店舗らしい画像を優先
- 適切な候補がなければ `og:image`
- それもなければ NO IMAGE

## 反映方法
GitHubの既存ファイルをv0.6で上書きしてCommitし、
Actions → Update Ramen Radar → Run workflow を実行してください。

成功後の `data/ramen.json`:
- `version`: `0.6`
- `policy`: `strict-change-only`
- `history_mode`: `current-scan-only`

NetlifyはGitHub連携済みなので自動デプロイされます。
