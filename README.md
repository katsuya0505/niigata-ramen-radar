# NIIGATA RAMEN RADAR v0.7

## v0.7 の変更
- トップの大型レーダーを小型化し、更新情報を最優先に表示
- 「今日 / 7日間 / 30日間」の期間切替を追加
- strict-change-only の精度を維持しつつ、同一イベントを重複排除して履歴保存
- 外部記事写真の表示を停止（著作権・利用条件への配慮）
- 写真領域を位置情報/マップ領域へ変更
- 現時点で緯度経度がない項目は LOCATION プレースホルダー + MAPリンクを表示

## 更新時の重要事項
既存の履歴を残すため、GitHubへv0.7を反映するときは **data/ramen.json を上書きしない** でください。
collector.py が既存の data/ramen.json を読み込み、新しい検知情報を追加します。

## 次段階
店舗住所/緯度経度の取得を一次情報から安全に追加すると、カード内にOpenStreetMapを自動表示できます。
