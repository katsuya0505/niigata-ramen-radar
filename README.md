# 新潟ラーメンレーダー v0.5

## v0.5 の狙い
「動く」から「見せられる」へ。

### 改善
- v0.3 / v0.4 の旧誤検知を初回実行時に自動削除
- 店舗単体ではない「5選」「6杯」「スタンプラリー」「特集」を除外
- 店名が取れない記事は掲載しない
- `og:image` を `image_url` として取得し、カード先頭に写真を表示
- 画像取得失敗時はレーダー風プレースホルダー
- NEW / LIMITED / CLOSED / CHANGE を別集計
- フィルターも現行イベント種別に合わせて修正
- `extractor_version: 0.5` を付与し、以降の履歴精度を管理

## GitHubへの反映
v0.5フォルダの中身で既存リポジトリを上書きし、Commitしてください。

その後:
1. Actions
2. Update Ramen Radar
3. Run workflow
4. `data/ramen.json` の `version` が `0.5` になったことを確認

NetlifyはGitHub連携済みなので、その後は自動デプロイされます。

## 写真について
v0.5は各記事の `og:image` を技術的に参照して表示します。
一般公開・商用運用では、各媒体や画像権利者の利用条件を確認してください。
長期的には店舗公式画像・許諾済み画像・ユーザー投稿画像へ寄せる設計が安全です。
