# 新潟ラーメンレーダー v0.4

v0.4では「店名」と「写真」を強化しました。

## 主な変更
- 分類は原則タイトルだけで判定
- 本文に偶然「閉店」などがあるケースを除外
- 引用符内のラーメン店らしい固有名詞を優先して店名抽出
- 店名を抽出できない記事は掲載しない
- `og:image` を `image_url` としてJSONに保存
- フロントで画像付きカード表示
- 画像がない場合はレーダー風プレースホルダー
- version 0.4

## 注意
元記事の画像の扱いは各媒体の利用規約・権利条件に従う必要があります。
v0.4は技術的に `og:image` を参照できる構造にしていますが、
公開運用では利用許諾や公式画像の利用可否を確認してください。
